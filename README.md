# ICFACTORY

ICFACTORY é um framework de governança híbrida (humano + IA) para desenvolvimento de software auditável, rastreável e com evolução controlada. Este README é um ponto de orientação não-normativo: descreve o propósito do repositório e indica onde ler os documentos oficiais sem reproduzir regras constitucionais.

## O que é o ICFACTORY

ICFACTORY fornece um conjunto de documentos e práticas que definem como identificar autoridade, preservar evidência, auditar mudanças e governar a evolução de sistemas cognitivos e de software. O framework privilegia:

- rastreabilidade e evidência verificável;
- identificação explícita de autoridade antes de mudanças;
- auditoria e observabilidade como pré-condições para intervenção;
- separação clara entre documentos normativos e materiais de pesquisa.
